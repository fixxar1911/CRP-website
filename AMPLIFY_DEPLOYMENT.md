# AWS Amplify Deployment Guide for CRP Website (crpnj.com)

This repository is fully configured for continuous deployment on **AWS Amplify Hosting**.

---

## Quick Deployment Steps

### Option A: AWS Amplify Console (Recommended - 2 Minutes)
1. Go to the [AWS Amplify Console](https://console.aws.amazon.com/amplify/home).
2. Click **Create new app** > **Host web app**.
3. Select **GitHub** as your repository service provider and authorize access.
4. Select repository: `fixxar1911/CRP-website` and branch: `main`.
5. AWS Amplify will automatically detect the root [`amplify.yml`](file:///home/fixxar1911/Projects/CRP-website/amplify.yml) build specification.
6. Click **Save and Deploy**. Your site will be live within ~90 seconds!

---

## Custom Domain Setup for `crpnj.com`
1. In the AWS Amplify Console side menu, navigate to **Domain Management**.
2. Click **Add Domain** and enter `crpnj.com`.
3. Amplify automatically configures free SSL/TLS certificates through AWS Certificate Manager.
4. Update your DNS settings at your domain registrar (Route 53, GoDaddy, Namecheap, etc.) with the CNAME and ALIAS records generated by AWS Amplify.
